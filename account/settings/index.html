Danger zone

Delete Veni Account

This permanently deletes the authentication account and the current private records linked to it through database cascades, including profile data, entitlements and saved Arcana readings/journal entries.

  • This cannot be undone.
  • It does not delete Veni Publishing’s public content.
  • Future legally required transaction records, if introduced, will need separate retention rules before commerce launches.
