# Veni Publishing preview — v2.1 visual polish

Apply this patch to `venipublishing-main/venipublishing-website-preview`.

## Review-driven changes

- Keeps the strong Independent Editorial House parent direction.
- Tightens the desktop homepage hero so supporting copy, CTAs and the lower platform nodes appear sooner on laptop-height screens.
- Slightly rebalances the six-node ecosystem orbit.
- Reduces navigation crowding after the addition of Veni Account.
- Makes the provisional Arcana hero treatment feel more intentional while still clearly leaving the final Arcana identity open.
- Replaces the long visible Arcana placeholder disclaimer with a quieter status line.
- Most importantly: on phones, the six-platform orbit becomes a readable 2×3 platform constellation instead of a shrunken desktop diagram.
- Bumps the v2 stylesheet query string to `v=2.1` to reduce stale-cache confusion.

No authentication, payments, database logic or production routes are changed.
`/kids/` remains untouched.
