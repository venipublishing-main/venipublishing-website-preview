# Veni Publishing — v3.1 Navigation & Linkage Hardening

Target: preview repository only.

This patch addresses discoverability rather than adding new backend features.

## Changes

- Veni Account becomes a genuine account hub rather than just a landing page.
- Adds persistent Account Tools navigation across:
  - Account home
  - My Library
  - Settings
  - Sign in
  - Register
- Adds direct links from the account hub to:
  - Arcana Draw
  - Saved Readings
  - Arcana Journal
- Adds a persistent Arcana subnavigation to the Arcana overview page.
- Adds direct Account links to the Arcana overview footer.
- Cleans user-facing Stage 2 testing language from Library/Settings.
- Bumps account CSS/JS query strings to v3.1 to avoid stale-cache confusion.

## Deliberate scope

This is the first linkage hardening pass.
A later final pre-production navigation audit should still scan every public route and platform footer/header for:
- Account entry points
- Library
- Settings
- Arcana Draw
- Saved Readings
- Journal
- future Mythos premium-reader routes

No database migration is required.
No Veni Kids files are changed.
