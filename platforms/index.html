How to read the portfolio

Status matters.

Active, publishing soon, planned and in development are not interchangeable labels.

The site uses status language deliberately so visitors can distinguish an existing public channel from a forthcoming book, a developing fictional series or a software prototype.

ActivePublic work exists now.
Publishing soonA specific release is being prepared.
In developmentThe concept or prototype exists, but the public service/product is not launched.
PlannedDirection is established, but no live public offer is implied.
